# 7D Zone Admin Panel

A single-page admin dashboard (v2) for the 7D Zone project, built with plain HTML, CSS and JavaScript.

## Features

- Self-contained: all markup, styles and scripts live in `index.html`
- No build step or dependencies required

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Higer23/7D-AdminPanel.git
   cd 7D-AdminPanel
   ```
2. Open `index.html` in any modern browser.

No server is required for basic viewing. If the panel talks to a backend, configure its endpoint inside the script section of `index.html`.
